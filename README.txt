PORTFOLIO VAN BALOUCKOU

LANCEMENT
1. Décompresse le fichier ZIP.
2. Ouvre le dossier van-portfolio.
3. Ouvre index.html dans ton navigateur.

CONTENU
- index.html : contenu et structure du site.
- style.css : direction artistique, animations et affichage mobile.
- script.js : menu mobile, animation terminal et apparition des cartes.
- assets/portrait.webp : portrait extrait du CV.
- assets/CV-Van-Balouckou.pdf : CV téléchargeable depuis le site.

PERSONNALISATION
Les textes, projets, coordonnées et liens se modifient dans index.html.
Les couleurs et styles se modifient dans style.css.
Les interactions se modifient dans script.js.

Le site est statique. Aucune installation n'est nécessaire.
Tu peux le publier avec GitHub Pages, Netlify ou Vercel.

NOTE
Les sections Hack The Box, OSINT et Red Team présentent des axes d'apprentissage.
Les write-ups sont indiqués comme étant en construction. Aucun résultat de laboratoire
ou certification non confirmé n'est présenté comme acquis.
